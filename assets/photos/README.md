# Fotos das viagens

O formulário local grava as fotos selecionadas nesta pasta quando você conecta a pasta do projeto. Elas são redimensionadas e recebem nomes automáticos; o catálogo em `assets/data/visits.json` associa cada arquivo à lembrança certa.

Tudo nesta pasta ficará público se o site for publicado. Escolha apenas fotos que você e sua família queiram compartilhar.
